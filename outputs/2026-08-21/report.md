# 2026年8月21日（金） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

**米イラン対立の深刻化と原油高**

トランプ大統領がイランの経済を壊滅させると脅迫したことで、米国とイランの対立解消への期待がさらに後退した。WTI先物は前日比約2.9%上昇し86.83ドル、ブレント原油も同様に上昇して93.2ドルに達した。両原油は過去7日間で約7〜8%上昇している。財務長官ベッセント氏は月曜日にイランおよびその取引相手国に対する具体的な措置を発表する予定とされており、この動きが米中関係の現在の均衡を不安定化させる可能性も指摘されている。

**米長期金利の再上昇と財政懸念**

金融市場では米国の借り入れコスト上昇が引き続き焦点となった。米財務省による長期債の買い戻し拡大の効果は短命に終わり、30年債利回りは前2日間で5.31%から5.19%へ低下した後、5.25%へ再上昇した。ベッセント氏は夏場の薄商い時の秩序ある取引確保が目的と説明しつつ、新たな財政計画の中で財政健全化に一層注力する方針を示した。サンフランシスコ連銀のメアリー・デイリー総裁は「7月の据え置きを強く支持した。最近のインフレと労働市場のデータはその判断を変えるものではない」と述べ、セントルイス連銀のアルベルト・ムサレム総裁は債券利回り上昇について「政府の資金調達とAI投資拡大による資本の争奪が起きている。インフレ期待は安定しており、FRBの信認は問われていない」と語った。S&P500は0.9%下落し今月最大の下げを記録。ユーロ・ストックス50も0.3%下落した一方、日経平均は1.4%上昇（ただし今週前半に5.5%超の下落があった後の反発）、ASX200は0.3%上昇した。

**豪雇用統計の下振れとRBA見通し**

7月の豪労働力調査（LFS）は予想外の下振れとなり、雇用者数が1万5800人減少した。労働参加率は0.1ポイント低下し66.9%となった。この結果を受け、豪州の利回りは全年限で4〜5ベーシスポイント低下した。RBAの今年中の追加利上げに対する市場の織り込み確率は約半分に低下した。金は前日比0.0%の4510.84ドルと横ばいで推移したが、前日は4%超の上昇を記録しており、月末比では11.6%の上昇となっている。米新規失業保険申請件数は前週比で小幅低下し20万6000件となり、解雇が歴史的に低い水準にとどまっていることを示した。フィラデルフィア連銀製造業景況指数は8月に41.4から47.4へ上昇し、市場予想の24.8を大幅に上回った。米景気先行指数は7月に前月比0.2%上昇し、経済がおおむね潜在成長率近辺で推移していることを示唆した。

## 2. テクニカル分析と本日の展望

**USD/JPY（現値: 159.05）― 上昇**

円は前日比0.6%下落し、159円台を回復した。米30年債利回りが5.25%へ再上昇するなど米長期金利が上昇圧力を受ける中、ドル指数（DXY）は前日比0.0%と概ね横ばいで推移した。本日は日本の7月消費者物価指数（CPI）や製造業・サービス業PMI速報値の発表が予定されており、日銀の政策見通しに影響を与える可能性がある。

**AUD/USD（現値: 0.7112）― 下落**

豪ドルは前日比0.2%下落し0.7112となった。7月の豪雇用者数が1万5800人減と予想外の減少となり、RBAの追加利上げに対する市場の織り込み確率が約半分に低下したことが背景にある。豪州の10年債利回りは5.01%と前日比5ベーシスポイント低下した。鉄鉱石は前日比0.4%下落し95.95ドルとなった一方、原料炭は1.0%上昇し229.00ドル、一般炭は0.9%上昇し138.30ドルとなった。

**XAU/USD（現値: 4510.84）― 横ばい**

金は前日比0.0%と横ばいで推移した。前日は4%超の上昇を記録しており、月末比では11.6%の上昇となっている。VIX指数は7.5%上昇し16.01となるなど市場の変動性が高まる中、金は高水準を維持している。原油価格の上昇や米財政懸念が続く環境下での推移となっている。

**EUR/USD（現値: 1.1679）― 横ばい**

ユーロは前日比0.0%と横ばいで推移した。原文によればユーロは横ばいで推移したとされており、ドル指数も前日比0.0%と概ね変わらなかった。ドイツ10年債利回りは3.26%と前日比変わらず、ユーロ圏の財政動向は英国ほど懸念が高まっていない状況が続いている。本日はユーロ圏の製造業・サービス業PMI速報値および消費者信頼感指数速報値の発表が予定されている。

**GBP/USD― 上昇**

原文にGBP/USDの直接の現値記載はないが、原文に「GBP gained 0.2%」と明記されているため、ポンドは対ドルで0.2%上昇と判断する。英国では財政動向への投資家懸念が引き続き高く、英国債（ギルト）利回りは全年限で約2ベーシスポイント上昇し、10年利回りは5.07%となった。本日は英国の7月小売売上高や製造業・サービス業PMI速報値の発表が予定されており、ポンドの方向感に影響を与える可能性がある。なお、AUD/GBPの前日比は-0.3%、AUD/USDの前日比は-0.2%であり、クロス計算からもポンドが対ドルで上昇方向であることと整合する（原文の直接記載を最優先とする）。
