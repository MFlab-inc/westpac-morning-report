# 2026年9月3日（木） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

**中東緊張と原油続伸**

トランプ大統領がイランとの合意について「彼らにとって価値のない合意など全く気にしない」とSNSに投稿し、交渉進展への期待が後退した。米国がイランへの最新の攻撃を実施したと発表したことも重なり、原油相場は続伸。WTI先物は0.5%高の90.63ドル、Brent原油は0.6%高の95.2ドルとなった。

**豪GDP上振れとRBA利上げ観測の高まり**

国内では第2四半期GDP成長率が前期比0.4%と予想をやや上回り、年率では2.1%となった。経済は勢いを失いつつも底堅さを維持していることが確認された。この結果を受けてRBAのタカ派的な見通しが市場で一段と織り込まれ、豪州3年国債利回りは10bp上昇して4.82%、10年国債利回りは5bp上昇して5.23%となった。スワップ市場では9月利上げ確率が69%、11月利上げは完全に織り込まれており、年末のキャッシュレート予想は4.69%まで引き上げられた。

**株式・債券・コモディティ市場**

米国株式市場は3日続落から反発し、S&P500が0.5%高、ダウ・ジョーンズが0.6%高、NASDAQが0.5%高となった。一方、欧州・アジア株は軟調で、ユーロ・ストックス50が0.1%安、FTSE100が0.3%安。アジアでは高い原油価格が重荷となり、KOSPIが4.0%下落、日経225が2.9%下落、ハンセン指数が0.1%下落した。ASX200も1.0%下落し、RBA追加引き締め観測が重しとなった。

米国債は小幅に上昇し、2年債利回りが3bp低下して4.37%、10年債利回りが2bp低下して4.78%となった。FRBの12月利上げはフューチャーズ市場で完全に織り込まれており、10月利上げ確率も約90%となっている。年末のフェデラルファンズ金利の予想水準は4.0%となっている。

金は1.2%上昇して4381.58ドルと反発した。銅は世界経済の成長見通しへの懸念から0.4%下落し、鉄鉱石は2.1%下落した。原料炭は2.5%下落して272.00ドル、一般炭は0.8%上昇して148.90ドルとなった。

ニュージーランドでは、RBNZが政策金利（OCR）を25bp引き上げて2.75%とした。これは市場の広範な予想通りの結果であった。

米国では、8月のADP雇用者数が38,000人（前回は修正後46,000人）と予想の47,000人をやや下回った。7月の米製造業受注は0.9%増。耐久財受注（輸送機器除く）は0.4%増で確認され、コア指標（国防・航空機除く）は0.2%から0.0%へ下方修正された。FRBの8月ベージュブックでは、12地区のうち10地区で「わずかから緩やかな」成長が報告された。カナダ銀行は9月の政策金利を据え置いた。

## 2. テクニカル分析と本日の展望

**USD/JPY（現値：158.71）― 下落（円高）**

円は対ドルで0.9%上昇し、USD/JPYは158.71となった。原文では「円が対ドルで大幅に上昇し、日本当局による介入の可能性に市場が警戒している」と明記されている。DXYは0.1%低下して99.56となっており、ドル全般の小幅な軟化も背景にある。米2年債利回りが3bp、10年債利回りが2bp低下したことも併記されている。

**AUD/USD（現値：0.7168）― 上昇**

AUDは対ドルで0.3%上昇して0.7168となった。豪Q2GDPが前期比0.4%と予想をやや上回り、RBAの追加引き締め観測が強まったことが背景として原文に記載されている。豪3年国債利回りが10bp上昇するなど、金利市場でも豪ドルを支援する動きが見られた。DXYが0.1%低下したことも豪ドルの上昇と並行している。

**XAU/USD（現値：4381.58）― 上昇**

金は前日比1.2%上昇して4381.58ドルとなった。原文では「米国債利回りの低下が支援材料となり金が反発した」と記載されている。米2年債利回りが3bp、10年債利回りが2bp低下したことが背景として挙げられている。中東情勢の緊張継続も市場環境として存在している。

**EUR/USD（現値：1.1588）― 横ばい**

ユーロは対ドルで変化なし（0.0%）となり、EUR/USDは1.1588で推移した。原文では「ユーロは変化なし」と明記されている。欧州株はユーロ・ストックス50が0.1%安と軟調であったが、為替レートへの影響は原文に記載がない。DXYが0.1%低下する中でユーロが横ばいにとどまった。

**GBP/USD（原文のFXレート表に現値の記載なし）― 下落**

原文のFXレート表にGBP/USDの直接の現値記載はない。原文本文には「ポンドは0.2%下落した（sterling fell 0.2%）」と明記されており、これを最優先の根拠としてGBP/USDは下落と判断する。なお参考として、AUD/GBPが前日比+0.6%、AUD/USDが前日比+0.3%であることから、クロス計算上もGBP/USDは対ドルで下落方向と整合する。欧州株が軟調であったことも原文に記載されている。
