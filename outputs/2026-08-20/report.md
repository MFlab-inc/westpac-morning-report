# 2026年8月20日（木） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

昨夜の市場は強弱まちまちの展開となった。最大の市場イベントは、米財務省が長期債の買い戻し（バイバック）オペレーションを少なくとも倍増させると発表したことである。これを受けて米国債は長期ゾーンを中心に上昇（利回り低下）し、2年債利回りが1bp低下、10年債利回りが6bp低下、30年債利回りが9bp低下した。米国債利回りの低下に伴い米ドルは主要通貨に対して広く売られ、DXY（ドル指数）は0.9%下落して98.79となった。米国株式はこの発表を好感し、S&P500が0.2%高（4日ぶりの上昇）、ダウ工業株30種平均とNASDAQもそれぞれ0.2%上昇した。

一方、アジア市場では半導体株の売りが継続し、半導体関連銘柄の比重が高いKOSPIが5.8%下落、日経平均株価も3.2%下落した。香港ハンセン指数は0.1%上昇と底堅く、ASX200は前日のウォール街の軟調を引き継ぎ0.2%下落した。欧州ではユーロ・ストックス50が0.4%下落、英FTSE100が0.1%上昇と方向感が分かれた。

コモディティ市場では、米国とイランの対立が解消に向かう兆しが見られないなか、WTI原油先物が0.9%上昇して85.67ドルと4日続伸した。金は長期米国債利回りの低下を背景に4.2%上昇し、4,515.63ドルと4,500ドルの節目を上抜けた。鉄鉱石は0.2%下落、原料炭は山西省の鉱山事故以降の中国国内供給制約に関する報道を受けて0.6%上昇した。

7月のFOMC議事録では、インフレが想定以上に長引く可能性を「多くの」参加者が指摘したことが明らかになった。「ほとんどの参加者は、関税や以前のエネルギー価格上昇の影響が薄れるにつれ、年内にインフレが低下すると予想したが、多くの参加者はインフレが持続的に高止まりする可能性を指摘した」とされる。また、インフレが低下しない場合は追加引き締めが必要との見方も示された。先物市場が織り込む年末のFF金利は3.85%にとどまり、市場は追加利上げの完全な織り込みには至っていない。英国の7月CPI（消費者物価指数）は前年比2.9%上昇と予想どおりで、コアインフレは2.6%で横ばいとなった。

豪州では、2026年第2四半期の賃金価格指数が前期比0.8%上昇した。民間部門の賃金上昇の鈍化が、公共部門の賃金上昇加速によって一部相殺された。豪州金利スワップ市場は今年中のRBA利上げを引き続き織り込んでおらず、年末の政策金利の市場予想は4.50%となっている。豪州3年債利回りは3bp低下して4.57%、10年債利回りは4bp低下して5.06%となった。なお、日本の10年債利回りは6bp低下して2.90%となった。

## 2. テクニカル分析と本日の展望

**USD/JPY（現値: 158.16）― 下落（↓）**
前日比-0.9%と円高ドル安が進行した。米財務省の長期債買い戻し倍増発表を受けてDXYが0.9%下落し、ドル全面安の流れのなかで円も対ドルで上昇した。日本の10年債利回りも6bp低下して2.90%となっており、米日金利差の縮小が意識されやすい局面にある。本日は豪州雇用統計（日本時間10:30）や米フィラデルフィア連銀製造業景気指数・新規失業保険申請件数（日本時間21:30）が注目材料となる。

**AUD/USD（現値: 0.7125）― 上昇（↑）**
前日比+0.5%と豪ドルが上昇した。DXYの0.9%下落というドル安の流れが主な背景にある。本日は豪州7月雇用統計（雇用者数変化の予想：+1.2万人、失業率予想：4.4%）が発表予定であり、結果次第で豪ドルの方向感に影響を与える可能性がある。AUD/GBPは前日比0.0%（横ばい）であった。

**XAU/USD（現値: 4,515.63）― 上昇（↑）**
前日比+4.2%と大幅に上昇し、4,500ドルの節目を上抜けた。米国の長期国債利回りが低下（10年債-6bp、30年債-9bp）するなか、金が買われた。米イラン対立の継続も地政学的リスクとして意識されている。CRB指数も0.9%上昇しており、コモディティ全般に強い地合いが続いている。

**EUR/USD（現値: 1.1677）― 上昇（↑）**
前日比+0.9%と上昇した。DXYが0.9%下落するなかでユーロも対ドルで上昇した。ユーロ圏の株式指標であるユーロ・ストックス50は0.4%下落しており、株式市場とFX市場の方向感は異なる動きとなった。ドイツ10年債利回りは前日比変わらずの3.26%であった。

**GBP/USD― 上昇（↑）**
原文のFXレート表にGBP/USDの直接の現値記載はない。原文には「sterling gained 0.6%」との記述があり、ポンドが対ドルで0.6%上昇したことが直接確認できる。なお、AUD/GBPが前日比0.0%（横ばい）、AUD/USDが前日比+0.5%であることとも整合的である。英国の7月CPI（消費者物価指数）は前年比2.9%上昇と予想どおりで、コアインフレは前年比2.6%で横ばい、サービスインフレは3.6%から3.4%へ低下した。英FTSE100は0.1%上昇した。
