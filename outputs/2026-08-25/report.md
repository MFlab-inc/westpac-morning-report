# 2026年8月25日（火） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

**主要テーマ①：米国の対イラン「経済D-Day」制裁**

トランプ大統領は70超のイラン関連企業を標的とする新たな制裁パッケージを発表し、テヘランと取引を続ける国々への措置も警告した。制裁の実効性は、イランの最大の石油顧客である中国に対して米国が実際に執行する意志を持つかどうかに大きく左右される。強硬な姿勢にもかかわらず、WTI原油先物は2.4%下落しUS$85.01/bblとなり、市場はイランが最終的に経済的圧力に屈するとの見方を示唆している。米国とカナダの間の貿易摩擦も依然として高水準にあり、トランプ大統領はカナダ製自動車・自動車部品への50%関税を1月から発動すると表明した。また、来月のトランプ・習会談を前に、中国の過剰製造能力への懸念から中国製品に追加7.5%関税を課す準備が進んでいるとの報道もあり、貿易政策の不確実性が成長の重荷となるとの懸念が強まっている。

**主要テーマ②：半導体株の下落とリスクセンチメントの悪化**

地政学的緊張の高まりに加え、今週後半に予定されるNvidiaの決算発表を前に半導体株が売られ、リスクセンチメントが悪化した。Nvidia、Seagate、Sandisk、Micronが主要な下落銘柄となり、メモリチップメーカーを追跡するETFは5.9%下落した。ナスダックは0.8%安、S&P500は0.3%安となった一方、ダウ・ジョーンズは0.3%上昇と相対的に底堅かった。欧州市場はまちまちで、ユーロ・ストックス50が0.2%安、DAXが0.2%安、CAC40が0.4%安となった一方、FTSE100は0.3%上昇した。アジア市場もまちまちで、ハンセン指数は1.9%下落、日経平均は0.7%下落した。国内ではS&P/ASX200が0.5%上昇し9,103となった。VIX指数は5.5%低下し15.13となった。

**主要テーマ③：債券市場の上昇と為替・コモディティ動向**

米財務省が手元資金を活用して高利回りの既発債を買い戻す可能性があるとの報道を受け、米国債に買いが入った。ただし利回りの動きは限定的で、米10年債利回りは4bps低下し4.70%、2年債利回りは4.23%で横ばいとなった。市場は2026年末までに約27bps、2027年末までに約50bpsの利上げを織り込んでいる。豪州債市場も利回りが低下し、3年国債利回りは3bps低下し4.53%、10年国債利回りは4bps低下し5.02%となった。OIS市場は年末の政策金利を約4.50%と示唆しており、追加利上げの可能性も意識されている。コモディティ市場はまちまちで、金は1.1%上昇、銅は0.4%上昇した一方、CRBインデックスは原油の2.4%下落を主因に0.8%低下した。鉄鉱石は1.8%上昇しUS$97.90/tとなり、原料炭は0.6%上昇、一般炭は0.9%上昇した。ACCU価格は4.3%下落した。

## 2. テクニカル分析と本日の展望

**USD/JPY（現値：159.01）― 小幅下落**

原文のFXレート表によるとUSD/JPYは前日比0.1%下落し159.01となった。米10年債利回りが4bps低下し4.70%となったほか、DXY（ドル指数）は0.1%低下し98.80となっており、ドルはやや軟調な地合いとなった。一方、市場は2026年末までに約27bpsの利上げを織り込んでおり、金利動向が引き続き注目される。本日は豪州時間午前11時30分（JST）にRBA議事録が発表されるほか、米国時間帯には住宅関連指標や消費者信頼感指数の発表が予定されている。

**AUD/USD（現値：0.7164）― 下落**

原文のFXレート表ではAUD/USDの現値は0.7164と記載されているが、本文では「豪ドルは0.3%下落しUS$0.7150」と記載されており、本文の値が直近の動向を示している。豪ドルは円、ポンド、ユーロ、人民元、香港ドル、シンガポールドルに対しても下落した一方、カナダドルに対しては0.4%上昇した。本日のRBA議事録発表が豪ドルの方向性を左右する可能性がある。DXYが0.1%低下し98.80となる中でも豪ドルが軟化した点は注目される。

**XAU/USD（現値：4603.07）― 上昇**

金は前日比1.9%上昇し4603.07ドルとなった。本文では「金は1.1%上昇」と記載されており、データスナップショットの変化率（1.9%）と本文の記述（1.1%）に差異がある（原文の記載をそのまま転記する）。対イラン制裁発動や米加・米中間の貿易摩擦継続など地政学的不確実性が高まる中、銅も0.4%上昇した。VIX指数は5.5%低下し15.13となっており、株式市場のボラティリティは低下しているが、金は引き続き上昇している。

**EUR/USD（現値：1.1677）― 横ばい**

原文のFXレート表によるとEUR/USDの前日比変化は0.0%で横ばいとなった。現値は1.1677。DXYは0.1%低下し98.80となっており、ドル全体はやや軟調だったが、ユーロはドルに対してほぼ動意なく推移した。欧州株式市場はまちまちで、ユーロ・ストックス50は0.2%安となった。本日は米国時間帯に消費者信頼感指数やニューヨーク連銀製造業景気指数などの発表が予定されており、ドルの方向性次第でユーロも動く可能性がある。

**GBP/USD（原文のFXレート表に現値の記載なし）― 上昇**

原文のFXレート表にGBP/USDの直接の現値・変化率の記載はない。原文にはAUD/GBP（前日比+0.7%）とAUD/USD（前日比+0.8%）の両方が記載されている。AUD/GBPが+0.7%上昇し、AUD/USDが+0.8%上昇していることから、GBP/USDは対ドルでAUD/USDとAUD/GBPの差分に相当する約+0.1%の上昇と導かれる。また、本文には「豪ドルはポンドに対しても下落した」との記載があり、ポンドが対豪ドルで上昇したことが確認できる。DXYが0.1%低下し98.80となる中、ポンドはドルに対して小幅上昇したとみられる。FTSE100は0.3%上昇し10,817となった。
