# 2026年9月14日（月） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

先週末の市場は強弱まちまちの展開となった。イランと湾岸諸国がオマーンでホルムズ海峡の船舶通航に関する協議を行う予定との報道を受け、原油価格は週末に反落した。Brentは2.8%下落してUS$105/bbl、WTIは2.4%下落してUS$100/bblとなった。ただし、Brentは週間では8.7%高を維持しており、この協議はその後延期されたと伝えられている。週末にかけてはフーシ派部隊が紅海沿岸地域へ前進したとの報告があり、イエメンでの戦闘が続いたほか、イラクから発射されたドローン攻撃によりサウジアラビアの東西パイプラインが閉鎖されるなど、地政学的緊張は依然として高止まりしている。

米国では8月の消費者物価指数（CPI）が前月比0.4%上昇（前月0.1%から加速）し、年率は3.4%で横ばいとなった。エネルギー価格が2.1%（前年比+16.3%）反発した一方、食料品は0.1%の上昇にとどまった。コアCPI（食料・エネルギー除く）は前月比0.3%・前年比2.4%と、7月の2.5%から0.1ポイント低下した。この結果を受け、先物市場は9月の利上げ確率を90%弱まで引き上げ、11月・12月の利上げも完全に織り込み、年末のフェデラルファンズ金利の市場予想は4.13%となった。また、ミシガン大学消費者態度指数（9月速報値）は51.7から47.8へ低下し、期待指数は51.5から45.8へ悪化した。1975年以降で1980年3月を除く最低水準となっている。

株式市場では、米国・欧州がCPI結果と原油安を好感して反発した。S&P500は0.9%高（週間では下落）、ダウ・ナスダックはともに1.0%高、Euro Stoxx 50は0.9%高、FTSE100は0.4%高となった。一方、アジア市場はエネルギー高騰が引き続き重荷となり、日経平均は1.9%安、KOSPIは1.8%安、ハンセン指数は0.6%安、ASX200は0.9%安と3月以来最弱の週となった。

豪州国債利回りは米国債の動きに連動しつつ、エネルギー価格上昇によるインフレ懸念も加わり、2011年以来の高水準に上昇した。3年債利回りは15bp上昇して5.00%、10年債利回りは12bp上昇して5.37%となった。スワップ市場は9月の利上げ確率を80%弱、11月の利上げを完全に織り込み、年末の政策金利予想は4.74%となっている。

コモディティでは、金がインフレ加速にもかかわらず0.7%上昇して4,349.08ドル、銅は横ばい、鉄鉱石は1.7%下落した。原料炭価格の高止まりが製鉄会社のマージンを圧迫している。一般炭は1.8%下落した。
