# 2026年9月8日（火） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

米国のレイバーデー（労働者の日）祝日により取引量が薄い中、週末に米国とイランがタンカーへの報復攻撃を繰り返したことが引き続きリスク心理の重石となった。原油価格はWTIが1.3%高の92.70ドル、Brentが0.7%高の97.0ドルと続伸したが、イランとオマーンがホルムズ海峡の通航管理に関する合意を数日内に発表できる可能性があるとの報道が伝わり、上昇幅はやや縮小した。

株式市場はまちまちの展開となった。米国株先物は下落し、ユーロ・ストックス50は0.2%の小幅高、ロンドンFTSE100は0.1%安。一方、半導体株の反発を追い風に東京市場（日経平均+2.1%）やソウル市場（+4.6%）は大幅高となった。上海総合も0.6%上昇した一方、香港ハンセン指数は0.9%下落した。ASX200は0.1%の小幅高にとどまった。

債券市場では、先週末の米国債の動きを受けて世界的に利回りが上昇した。豪州3年債は4bps上昇の4.78%、10年債は2bps上昇の5.20%と、先週付けた直近高値5.23%をわずかに下回る水準となった。独10年債（Bund）は5bps上昇の3.39%、英10年債（Gilt）は4bps上昇の5.17%（原文記載値）、日本10年国債は1bp上昇の2.93%となった。米国債は祝日で取引が薄く、10年債は4.78%で横ばいとなった。

ユーロ圏では、Q2GDP確報値が速報値の0.4%（前年比+1.0%）から0.6%（前年比+1.2%）へ上方修正された。家計消費の拡大が寄与した一方、政府支出はやや鈍化し、投資は下押し要因となった。センティックス投資家信頼感指数は9月に0.9から5.1へ上昇し、長期平均を上回った。豪州では、Q2労働勘定統計が月次雇用統計を上回る堅調な雇用増加ペースを示した。複数就業者比率が過去最高を更新しており、生活費上昇圧力が追加就業を促している構図が続いている。

国内市場では、本日午後のRBAチーフエコノミストによるファイヤーサイドチャットと、夜のRBA副総裁へのインタビューが注目される。先週のQ2GDP統計を受けた政策判断の方向性を示す可能性があり、スワップ市場では9月のRBA利上げ確率が約60%、11月は完全に織り込まれている。

## 2. テクニカル分析と本日の展望

**USD/JPY（現値: 154.37）**
方向感: 下落（円高・ドル安）。円が前日比1.2%上昇し、JPY155の節目を突破して2月以来の最高値水準に達した。ドル指数（DXY）も0.3%下落し98.93となっており、ドル全般の軟化が背景にある。原文は「以前の介入局面で到達した水準を超えた」と記述しており、円の上昇が市場で注目されている。

**AUD/USD（現値: 0.7217）**
方向感: 上昇。AUD/USDは前日比+0.2%と小幅に上昇し、0.72台を維持した。原文は「0.72ドル超えの水準を固めつつある」と記述している。ドル指数の0.3%下落が下支えとなる一方、RBAチーフエコノミストと副総裁の発言が本日の注目材料となる。スワップ市場では9月利上げ確率が約60%と、政策期待が豪ドルを支援している。

**XAU/USD（現値: 4404.30）**
方向感: 下落。金は前日比0.6%下落し、4,400ドル台をわずかに上回る水準となった。原文は「インフレ懸念と利回り上昇、米イラン情勢の混乱を背景に」と記述している。世界的に債券利回りが上昇する中、金価格は軟調に推移した。

**EUR/USD（現値: 1.1623）**
方向感: 上昇。ユーロは前日比+0.1%と小幅に上昇した。ユーロ圏Q2GDP確報値が0.6%（前年比+1.2%）へ上方修正されたほか、センティックス投資家信頼感指数が長期平均を上回る5.1へ改善したことが背景として原文に記載されている。ドル指数の0.3%下落も支援材料となった。

**GBP/USD（原文のFXレート表に現値の記載なし）**
方向感の導出: 原文のFXレート表にGBP/USDの直接の現値・変化率の記載はない。ただし、原文本文に「Sterling rose 0.2%」との記載があるため、これを最優先し、GBP/USDは前日比+0.2%の上昇と判断する。なお、クロス計算による補完（AUD/GBP前日比+0.1%、AUD/USD前日比+0.2%）でも同方向が示唆される。ドル指数が0.3%下落する中、ポンドは対ドルで0.2%上昇した。
