# 2026年8月14日（金） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

今週発表された米CPI（消費者物価指数）の結果が良好だったことを受け、来月のFED利上げ確率は週初めの過半数超から約3分の1程度まで低下した。この利上げ観測の後退が金融市場全体のセンチメントを支え、主要株価指数の上昇と国債利回りの低下を促した。米国債イールドカーブは3〜7bp低下し、10年債利回りは5bp低下して4.64%となった。

原油価格も下落し、相場の安定に寄与した。イラン支援のフーシ派がサウジアラビアのアラムコ製油所を標的にしたとの報道があったにもかかわらず、トランプ大統領が軍事行動から経済制裁・海上封鎖を中心とした最大限の経済的圧力へと戦略を転換したことで、市場は短期的な地政学リスクの高まりを警戒しなくなった。10月限ブレント先物は2ドル下落して87.0ドル、9月限WTI先物も同程度下落して81.3ドルとなった。

株式市場では、S&P500が0.7%上昇し年初来騰落率は約14%高に達した。テクノロジー株が牽引役となり、エネルギー・素材株は軟調だったものの上昇は幅広いセクターに及んだ。日経平均は1.2%高と大幅上昇した一方、ハンセン指数は0.2%下落し、アジア市場の方向感は一様ではなかった。ASX200は0.2%下落した。

日本では、高石首相がBOJの利上げを支持しているとの噂が流れ、日本国債利回りが小幅上昇した。英国のQ2 GDP成長率は前期比0.4%と市場予想に一致し、BOE予測（0.3%）をわずかに上回った。ユーロ圏の鉱工業生産は6月に横ばいで、前年比では0.1%増にとどまり、製造業の停滞が続いている。米PPIは7月に予想をやや下回り、ヘッドラインベースで前月比横ばい、食品・エネルギーを除くコアは前月比0.2%上昇だった。
