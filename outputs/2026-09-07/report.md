# 2026年9月7日（月） Westpac IQ Morning Report

## 1. ファンダメンタルズ・マクロ経済分析

金曜日の市場は「前半と後半で様相が一変した」展開となった。前半はFRB理事ウォーラー氏の発言を受けて追加利上げ懸念が和らぎ、相対的に落ち着いた取引が続いた。しかし後半、8月の米非農業部門雇用者数が16.2万人増と市場予想の5.5万人を大幅に上回ったことで、市場はFRBの追加利上げ観測を急速に再構築した。6月・7月分の上方修正も合わせて5.5万人に達し、3か月平均ペースは需給均衡の上限付近となる7.1万人へ切り上がった。平均時給は前月比0.3%・前年比3.1%と落ち着いた水準を維持し、失業率は参加率が0.2ポイント上昇したにもかかわらず4.1%で横ばいを保った。

トランプ大統領は雇用統計発表後、FRBのウォーシュ議長と理事会メンバーに対し「愛国者になれ」と呼びかけ、利下げを求める圧力を強めた。また週末には中東情勢が悪化し、米国がイランのタンカー3隻を攻撃、イランも対抗措置に出たと報じられた。

株式市場では、米国株が雇用統計の上振れを受けて下落し、S&P500は0.4%安（週間では上昇）、ダウ平均は0.5%安、NASDAQは0.3%安となった。一方、アジア市場は前半の緩和的なFRB観測を受けた楽観論に支えられ、香港ハンセン指数が1.7%高、日経平均が1.3%高、KOSPIが1.6%高を記録した。欧州ではユーロ・ストックス50が0.2%高、FTSE100は横ばいだった。豪ASX200は0.2%安で週を終えた。

米国債利回りは雇用統計後に上昇し、2年債が3bp上昇、10年債が1bp上昇した。先物市場では12月の利上げが引き続き完全に織り込まれ、年末のフェデラルファンズ金利の予想値は4.01%となった。豪州国債利回りはほぼ変わらず、3年債が1bp低下、10年債は横ばいだった。スワップ市場では9月利上げ確率が60%強へ上昇し、11月の利上げも完全に織り込まれ、年末の政策金利予想は4.65%となった。

コモディティ市場では、WTI原油が0.2%高の91.48ドルと7月末以来最高の週間終値を記録し、ブレント原油も0.8%高の96.3ドルとなった。金は1.0%下落し、銅は0.6%高、鉄鉱石は0.4%高だった。

ユーロ圏では7月の小売売上高が前月比0.6%減と予想を下回ったが、6月分が0.3%減から0.2%増へ上方修正されたことで、失望感の一部は相殺された。ニュージーランドでは第2四半期の建設工事量が前期比4.8%増と予想を上回り、住宅・非住宅ともに活動が強まった。
